•Constrained Convex Optimization Problem: A mathematical formulation that aims to minimize a convex objective function f(x) where the optimization variable x is restricted to a specific feasible set C (or D, M) that is convex and compact (i.e., bounded and closed).

•Frank-Wolfe (FW) Algorithm / Conditional Gradient Method: One of the earliest iterative methods for constrained convex optimization, it operates by minimizing a linear approximation of the objective function at the current iterate over the feasible domain, 
and then moving towards the resulting "FW vertex".

•Linear Minimization Oracle (LMO) / LMOC(g): For a given gradient g and a feasible set C, an LMO returns a point s that minimizes the linear function gᵀz over the set C. It is a key component of FW algorithms, enabling their "projection-free" nature.

•FW Vertex (sk): An extreme point of the feasible set C that minimizes the scalar product with the current gradient ∇f(xk) at iteration k, as identified by the LMO.

•Projection-Free Method: An optimization method that avoids computationally expensive projections onto the constraint set by instead relying on linear minimizations, as is characteristic of Frank-Wolfe methods.

•Iterate (x(k) / xk): A sequence of feasible points (or candidate solutions) generated by an iterative optimization algorithm.

•Duality Gap / FW Gap (g(x) / G(x)): A measure of approximation quality for a current solution x, defined as max s∈D <x-s, ∇f(x)>. It serves as an upper bound on the primal error f(x) - f(x*) and is automatically computed during each FW iteration.

•Primal Gap (hk): The difference between the objective function value at the current iterate xk and the optimal objective value f*, formally hk = f(xk) - f*.

•Curvature Constant (Cf / κf,C): A measure of the non-linearity of the objective function f over the domain M (or D, C). It quantifies how much f(y) deviates from its linearization at x, normalized by the squared step-size. 
It is affine invariant and closely relates to the Lipschitz continuity of the gradient.

•Geometric Strong Convexity Constant (µAf / µ̃f): An affine invariant constant that characterizes the strong convexity of the objective function f in relation to the geometry of the domain M. Its positivity is a condition for global linear convergence rates in some FW variants.

•μ-strongly Convex Function: A differentiable convex function f for which f(y) ≥ f(x) + ∇f(x)ᵀ(y - x) + μ/2 ||x - y||² for all x, y in its domain, with μ > 0. This implies a certain "lower curvature" or "pointedness".

•Active Set (S(t) / Sk / Ak): In FW variants, this is the set of "atoms" (or extreme points) that currently have non-zero weights in the convex combination representing the current iterate x(t). Maintaining this set is crucial for improved FW algorithms.

•Atoms (A): A finite set of vectors (or points) whose convex hull defines the domain M. Iterates of FW algorithms are often expressed as sparse convex combinations of these atoms.

•Projection Operator (proj(·, C)): An operator that computes the point in a closed convex set C that is closest (in Euclidean norm) to a given external point.

•Distance Function (dist(·, C)): A function that calculates the Euclidean distance from a point to a set C.

•Diameter (diam(C)): The maximum Euclidean distance between any two points within a set C.

•Indicator Function (ιC): A function that assigns a value of 0 if an element x is within a set C, and +∞ otherwise.

•Affine Invariance: A property indicating that an optimization method or its convergence analysis remains unchanged under affine transformations and re-parameterizations of the problem's domain. FW algorithms exhibit this property.

•**0-norm (‖x‖0):** A pseudo-norm that counts the number of non-zero entries in a vector x`.

•Euclidean Norm (‖x‖ / ‖x‖2): The standard L2 norm of a vector x, defined as √xᵀx. For matrices, it's referred to as the Frobenius norm (‖·‖F).

•**p-norm (‖x‖p):** A generalized vector norm for p ≥ 1`.

•Signum Function (sgn or sign): A function that returns 1 for positive inputs, -1 for negative inputs, and 0 for zero.

•Normal Cone (NC(x)): For a set C at a point x ∈ C, it is the set of vectors r such that rᵀ(y - x) ≤ 0 for all y ∈ C. First-order stationarity conditions are equivalent to the negative gradient being in the normal cone.

•Convex and Compact Set: A set C is convex if, for any two points in C, the line segment connecting them is entirely within C. It is compact if it is both closed and bounded.

•Lipschitz Continuous Gradient: A property of a function f where the norm of its gradient ∇f satisfies ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖ for all x, y in its domain and some constant L > 0. This implies a quadratic upper approximation of f.

•Relative Interior (ri(C)): The interior of a set C when considered within its affine hull.

Frank-Wolfe Variants
•Away-Steps Frank-Wolfe (AFW): An improved FW variant that can take a step "away" from a "bad" atom in the current active set, in addition to the standard step "towards" a "good" FW atom. 
This helps prevent zig-zagging and achieve linear convergence for strongly convex functions.

•Away Direction (dAt): In AFW, the direction x(t) - vt, where vt is an atom in the active set S(t) that maximizes the inner product with the gradient, indicating a point to move away from.

•Pairwise Frank-Wolfe (PFW): A FW variant that focuses on moving weight mass directly between the "away atom" (vt) and the "FW atom" (st) in each step, rather than uniformly reducing weights of all active atoms. Its direction is dPFWk = sk - vk.

•Fully-Corrective Frank-Wolfe (FCFW): A more computationally intensive FW variant that, after adding a new atom, fully re-optimizes the objective function over the entire current active set (or a correction polytope defined by a set of atoms). 
This aims for greater progress per iteration.

•Wolfe’s Minimum Norm Point (MNP) Algorithm: A specific type of FCFW, particularly effective for quadratic objectives over polytopes. It implements the "correction" step by sequences of affine projections onto the active set.

•FW Method with In-Face Directions (FDFW) / Decomposition Invariant Conditional Gradient (DiCG): A FW variant similar to AFW, but where the search for the "away atom" is restricted to the minimal face of the constraint set C that contains the current iterate xk.

•Extended FW (EFW) / Simplicial Decomposition: A FW variant that minimizes the objective function over an expanded active set Ak+1 (typically Ak plus the new FW atom) at each iteration.

•Block Coordinate Frank-Wolfe (BCFW): An extension of FW designed for optimization problems over "block product domains" (e.g., C = C(1) × ... × C(m)). It works by selecting a random block and performing a FW step within that block.

•Approximate Linear Minimization Oracle: An LMO that, instead of providing an exact minimizer of the linear subproblem, returns a solution within a specified additive approximation quality δ.

•Zig-Zagging Phenomenon: A characteristic slow convergence behavior of the classical FW algorithm, especially when the optimal solution lies on the boundary of the feasible set. 
Iterates oscillate back and forth between vertices defining the face containing the solution, leading to a sublinear convergence rate.

•Drop Step: An iteration in certain FW variants (AFW, MNP, PFW) where an atom is completely removed from the active set by setting its weight to zero, resulting in a reduction in the active set size.

•Swap Step (in PFW): A specific type of step in the Pairwise Frank-Wolfe algorithm where weight is fully transferred from an "away atom" to a "FW atom", but the overall size of the active set remains unchanged.
Convergence & Geometric Properties

•O(1/t) / O(1/k) Convergence Rate: A sublinear convergence rate typically observed for the classical Frank-Wolfe algorithm on general convex objectives, where the optimality gap decreases proportionally to 1/t (or 1/k) over time (or iterations).

•Linear Convergence Rate (O((1-ρ)t)): A faster convergence rate where the optimization error decreases geometrically (exponentially fast), often achieved for strongly convex objective functions or with specific FW variants like AFW.

•Pyramidal Width (PWidth(A)): A geometric quantity associated with a set of atoms A (defining a polytope M). It represents a "condition number" of the constraint set, 
providing a lower bound on the angle between the negative gradient and the pairwise FW direction, which is critical for proving global linear convergence rates. 
It can be defined as min F∈faces(C) dist(F, conv(A \ F)).

•Directional Width (dirW(A, r)): For a set A and a direction r, it's defined as max s,v∈A <r/||r||, s-v>, representing the maximum extent of the set in that direction.

•Pyramidal Directional Width (PdirW(A, r,x)): A variant of directional width defined with respect to a base point x and an active set S, considering the maximum inner product between the normalized direction r and s-v for s from A and v from S.

•Angle Condition: A condition −∇f(xk)ᵀd̂k ≥ τ * ||xk − x*|| * ∇f(xk)ᵀ(xk − x*) for some τ > 0, which if satisfied by the chosen descent direction d̂k, is instrumental in proving linear convergence rates for strongly convex objectives.

•Vertex-Facet Distance (ΩC): A geometric constant for a polytope C, defined as the minimum distance between any vertex v of C and any supporting hyperplane H (containing a facet) that does not contain v. 
It can be used to derive constants in the angle condition for PFW.

•Support Identification: A property, primarily of AFW for strongly convex objectives, where the algorithm is able to identify the minimal face of the feasible set containing the optimal solution in a finite number of iterations.

•Inexact Linear Oracle: The scenario where the LMO is not solved exactly, but rather returns a point s̃k that satisfies ∇f(xk)ᵀ(s̃k − xk) ≤ min s∈C ∇f(xk)ᵀ(s − xk) + δk for some non-negative approximation error δk.

•Hoffman Constant: A constant associated with a system of linear inequalities, used in the context of generalized strong convexity conditions for functions that are not necessarily strongly convex but are compositions with affine transformations.
Step-Size Strategies

•Unit Stepsize (αk = 1): A fixed step-size where the algorithm moves entirely along the chosen direction. It is often used for problems with concave objectives and can guarantee finite convergence under certain assumptions.

•Diminishing Stepsize (αk = 2/(k+2)): A step-size rule commonly used in the classical Frank-Wolfe algorithm, where the step size decreases with the number of iterations k.

•Exact Line Search: A step-size strategy that determines the optimal step size αk by minimizing the objective function f along the current search direction dk, i.e., αk = argmin α∈[0,αmaxk] f(xk + α dk).

•Armijo Line Search: An adaptive step-size method that iteratively shrinks the step size until a sufficient reduction in the objective function value is guaranteed by a predefined condition.

•Lipschitz Constant Dependent Step Size (αk = min{-∇f(xk)ᵀdk / (L‖dk‖²), αmaxk}): A step-size determined by explicitly using the Lipschitz constant L of the gradient to optimize a quadratic model that overestimates the objective function along the search direction.

Applications & Domains
•L1-Ball / Cross-Polytope: The set of vectors x in Rⁿ whose L1 norm Σ|xᵢ| is less than or equal to a constant a. It is the convex hull of signed unit basis vectors and is crucial for sparse optimization problems.

•Standard Simplex (Δn-1 / ∆n): A polytope defined as the set of non-negative vectors x in Rⁿ whose elements sum up to a constant a (often 1). It is the convex hull of standard unit basis vectors.

•**p-Balls (p ∈ ]1, +∞[):** The set of vectors xinRⁿwhoseLpnorm||x||pis less than or equal to 1. These are generalizations of theL1andL2` balls.

•Nuclear Norm-Ball / Trace Norm-Ball (‖X‖∗ / ‖X‖nuc): The set of matrices X in Rᵐˣⁿ whose nuclear norm (the sum of its singular values) is less than or equal to a constant. It serves as a convex relaxation for rank constraints and is the convex hull of rank-1 matrices.

•Flow Polytope (FG): A convex set representing the set of unit flows x on a single-source single-sink directed acyclic graph (DAG) G.

•Birkhoff Polytope / Assignment Polytope (Bn): The set of all n×n doubly stochastic matrices. It is the convex hull of permutation matrices and is relevant for matching and ranking problems.

•Permutahedron (Pw): The convex hull of all n! permutations of the entries of a given vector w.

•Submodular Polyhedron (Polymatroid): A convex set Pg defined from a submodular function g, representing a region Pg := { x ∈ R^V : Σ_{a∈A} s_a ≤ r(A) for all A ⊆ V, Σ_{a∈V} s_a = r(V) }. Linear optimization over this domain can be done efficiently with a greedy algorithm.

•Atomic Norms (ΩD(x)): A gauge function ΩD(x) := inf {t≥0 | x ∈ tD} for a convex set D which is the convex hull of another set A. These generalize standard norms and are useful for structured sparsity problems.

•Support Function (Ω∗D(y)): For a set D, Ω∗D(y) := sup s∈D <s,y>. For atomic domains, this function simplifies to finding the maximum inner product with an atomic element, sup s∈A <s,y>, which is often easier to compute.

•Structured Atomic Norms: Generalizations of atomic norms that induce more complex and structured notions of sparsity, often involving grouping of indices.

•Schatten Matrix Norms: A class of matrix norms defined based on the singular values of a matrix, including the trace norm (Schatten L1-norm) and the operator norm (Schatten L∞-norm).

•Operator Norm Ball (‖.‖op-ball): The unit ball of the standard matrix operator norm, which is the Schatten L∞-norm. It is the convex hull of all orthonormal matrices.

•Permutation Matrices: Square matrices with exactly one entry of 1 in each row and column, and 0s elsewhere. They represent permutations.

•Rotation Matrices: Orthogonal matrices with a determinant of one, representing rotations in space.

•Factorized Matrix Norms: A framework for optimization where the matrix domain is formed by factorizations, i.e., the atomic set consists of outer products of elements from two other atomic sets.

•Matrix Max-Norm: A matrix norm used in certain semidefinite optimization problems, for which FW methods provide the first convergence guarantees.

•Traffic Assignment Problem: A classic optimization problem in transportation networks that seeks to find traffic patterns satisfying equilibrium conditions, often formulated as a non-linear multicommodity network flow problem.

•Submodular Function (r): A set function r: 2^V → R such that for every A, B ⊂ V, r(A) + r(B) ≥ r(A ∪ B) + r(A ∩ B).

•Base Polytope (B(r)): A specific polytope defined by a submodular function r, important for submodular optimization.

•LASSO Problem: A widely used technique in sparse linear regression and signal processing, formulated as minimizing a squared L2-norm loss subject to an L1-norm constraint on the solution vector.

•Matrix Completion: The problem of recovering a low-rank matrix from a sparsely observed set of its entries. It is commonly relaxed to an optimization problem over a nuclear norm ball.

•Adversarial Examples / Attack: Maliciously perturbed inputs designed to cause misclassification in a machine learning model. An adversarial attack aims to subtly modify a correctly classified data point to trigger misclassification.

•Minimum Enclosing Ball (MEB) Problem: The problem of finding the smallest ball (defined by its center and radius) that encloses a given set of points.

•Standard Quadratic Optimization Problem (StQP): A convex quadratic programming problem in the form min {xᵀAᵀAx - bᵀx : x ∈ Δn-1} where Δn-1 is the standard simplex.

•Clique in a Graph: A subset of vertices in an undirected graph where every two vertices are connected by an edge. A maximal clique is a clique not contained in any strictly larger clique.

•Sparse Point in a Set: A point x within a given polyhedron P that has the maximum possible number of zero components, effectively aiming for a sparse solution.

•Block Product Domains: Optimization domains that can be expressed as a Cartesian product of several smaller, independent constraint sets, C = C(1) × ... × C(m).

•Cloud Oracle: A concept in asynchronous and parallel optimization where worker nodes (modeling a "cloud") send information (e.g., LMO solutions) to a central server at potentially different times, introducing delays.
